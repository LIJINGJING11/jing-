# 新春酒店促销海报分层源文件

- 画布：1088 × 1445 px，RGB，8 bit。
- Photoshop 源文件：`新春酒店促销海报_可编辑分层源文件.psd`。
- 图层结构：1 个客房底图像素层、21 个独立 RGBA 透明 PNG 像素层、16 个可编辑 Photoshop 文字层，共 38 层。
- 每个装饰 PNG 使用全画布尺寸，便于在 PSD 中保持样图对应位置；PNG 原件位于 `assets/`。
- 文字使用 STSongti SC 字体族。打开时若目标电脑未安装该字体，Photoshop 可能提示替换字体。
- `新春酒店促销海报_预览.png` 是 PSD 当前合成效果预览。

## 样图与重建范围

附件图片作为构图与视觉参考，图中文字按可见内容重建为独立可编辑文字层。由于附件是扁平化图片，无法从中恢复原始客房摄影；PSD 的独立底图为依据样图重建的同风格客房画面。装饰图形按样图位置和色彩单独制作，未合并进背景。

地址和电话保留样图中的占位内容，可直接编辑替换。
