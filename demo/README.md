# 酒店素材工坊 · 本地酒店内容工具 Demo

完整的需求演进、对话决策、修改记录和验片结果见项目根目录的 [PROJECT_HISTORY.md](../PROJECT_HISTORY.md)，版本摘要见 [CHANGELOG.md](../CHANGELOG.md)。

## AI 自动成片 · 智能 EDL 实验模式

自动成片现在有两个剪辑引擎：默认的「智能 EDL」先用 Turing TTS 生成旁白，再尝试用 ASR/语音对齐得到时间轴，并把素材缩略图、镜头标签和旁白段落交给可配置的剪辑/视觉模型生成 EDL；服务端随后用 FFmpeg 渲染 MP4。字幕文案始终来自旁白时间轴，剪辑模型只能决定镜头，不能把画面分析写进字幕；导出使用 ASS 设计字幕（重点词、强调线、样式卡片），并把页面选择的背景音乐与旁白混音。模型或 ASR 未配置时，会明确回退到本地 EDL 初稿，不会把回退结果伪装成模型判断。导出失败时，浏览器仍会用原来的 Canvas + MediaRecorder 流程生成可预览的 WebM。

旧版「快速本地」引擎仍保留，使用原来的 Canvas 时间线和字幕渲染。此前 Seedance 版代码、页面和样式备份在项目根目录的 `backups/auto-edit-seedance-20260923/`，没有删除。

智能模式需要在「配置 API」中按需填写：

- 智能剪辑 / 视觉模型 ID：支持图片输入并能返回 JSON 的模型；
- 旁白时间轴 ASR 模型 ID：支持 word timestamps 的转录模型，可留空，留空时使用估算时间轴。

如果要让服务端使用项目依赖中的 FFmpeg，请在 `demo` 目录执行 `npm install`；也可以通过 `FFMPEG_PATH` 指定系统 FFmpeg。智能 EDL 的中间产物不会写入项目目录，服务端会在临时目录渲染后清理。

应用现在采用左侧双入口导航：第一项「工具」展示开机三件套、开机视频转换、Logo 黑白扣取、图片裁剪压缩、视频压缩，以及「一键去水印」「一键精修场景图」两个付费工具；第二项「模板运营图」进入酒店运营海报模板库和可编辑模板详情。前五个工具页和本地处理逻辑已从之前交付的安装包 `app.asar` 迁回当前项目，付费工具保留独立上传与处理入口，方便后续接入图像修复服务。

顶部精选风格卡走 AI 做同款：模型参考风格图与用户素材生成完整海报；下方酒店运营模板走本地拆分图层编辑，酒店实景图、PNG 蒙层、PNG 装饰/图标和文字严格按画布顺序叠加，文字由浏览器本地排版，保证小字清晰。当前已加入 03｜法式雅韵客房、04｜雅韵庭居客房、05｜艺境设计客房三个拆分模板、「PSD｜行政景观套房」横版 16:9 模板、原有的「PSD｜休闲度假酒店」竖版 2:3 PSD 模板、「PSD｜满房海报」竖版 9:16 PSD 模板、「PSD｜暑假特惠海报」竖版 PSD 模板，以及「PSD｜TCL酒店自助晚餐」941×1672 竖版模板。自助晚餐模板保留 19 个可见非文字独立 PNG 图层和 10 个可编辑 Photoshop Type 图层；隐藏的无字修复背景按 PSD 原状态记录但不参与显示。其他 PSD 模板继续使用各自独立的图层定义，没有被更改或替换。编辑区底层只使用纯实景图，模板预览图不会作为场景底图。

「AI 抠图」「擦除」「标记改图」「扩图」「变清晰」以及「一键精修场景图」在配置公司会员后均优先调用本地服务的公司 GPT‑Image 网关；擦除、标记改图和去水印会把画笔区域作为透明遮罩上传。去水印始终使用公司模型，不再回退本机网格识别，避免误伤海报标题、价格、日期、Logo 和产品边缘。其他付费工具只有本地服务未启动或没有配置 Key 时才回退到本机演示算法，401/403、模型权限和参数错误会直接提示。

进入本地编辑后，直接点击画布上的文字修改内容；右侧「文字样式」面板用于调整字号和行高。文字、蒙层、装饰、Logo 和二维码都可以拖动或删除；文本框缩放只改变宽高和换行，不会改变字号。顶部「← 返回上一步」返回模板库；画布下方「返回上一步」撤销最近一次编辑（移动、缩放、改字、调亮度/透明度等）。

## 只做本地模板编辑（无需 API Key）

如果只需要替换场景图、编辑文字、拖动图层和导出 PNG，直接双击：

```text
demo/start-local.command
```

脚本会启动本地页面并自动打开 `http://127.0.0.1:4174/`（端口被占用时会自动选择 4175-4178 或 4180）。脚本会按自身所在目录定位项目，不依赖固定的旧路径。

## 配置公司会员 API（无需修改脚本）

启动任意本地模式后，点击页面右上角的「配置 API」即可打开配置窗口。服务商选择「公司 GPT‑Image（公司会员）」，粘贴公司模型平台发放的网关 Key，确认模型 ID 和 API 地址后点击「保存并连接」。之后「一键精修场景图」、AI 风格海报和 5 个付费图片工具会共用这套配置。

保存后 API Key 会优先写入当前 macOS 用户的钥匙串，模型地址、模型 ID 等非敏感配置保存在本机权限为 600 的运行时配置文件中；前端代码、浏览器 `localStorage` 和源代码都不会保存 Key。之后重启 `start-local.command` 或 Node 服务会自动恢复配置，不需要再次输入。点击「清除当前配置」会同时删除钥匙串 Key 和本机运行时配置。公司会员是否允许图片 API 调用，以公司模型平台的权限为准。

如果页面提示找不到本地服务，请先双击 `demo/start-local.command`（只做本地编辑）或 `demo/start-gpt-image.command`（启动时读取公司网关 Key）。

## 用豆包 Seedream 启动（推荐 Demo）

直接双击：

```text
demo/start-doubao.command
```

首次启动时会弹出一个隐藏输入框，请输入火山方舟 API Key。输入后会保存到 macOS 钥匙串（不写入项目文件、不写入前端代码）；之后启动无需再次输入即可直接使用。

如需更换已保存的 Key，可在终端执行下面这行，再重新双击启动脚本：

```bash
security delete-generic-password -a "$(id -un)" -s "hotel-material-studio-doubao"
```

也可以在终端启动：

```bash
cd "/路径/到/酒店素材工坊"
MODEL_PROVIDER=doubao \
ARK_API_KEY="你的火山方舟 API Key" \
node demo/server.mjs
```

默认模型是：

```text
doubao-seedream-5-0-260128
```

如需切换模型，直接双击：

```text
demo/change-doubao-model.command
```

在弹窗中选择 Seedream 5.0 标准版、Seedream 4.5、Seedream 4.0 或 Seedream 5.0 Pro，脚本会自动读取已保存的 Key、启动新端口并打开新页面。不同模型是否可用，以火山方舟控制台中该账号的模型权限为准。

如果你在控制台选择的是 Seedream 4.0，可以改成：

```bash
DOUBAO_MODEL="doubao-seedream-4-0-250828"
```

API Key 管理入口：<https://console.volcengine.com/ark/apiKey>

## 公司 GPT-Image 启动

如果要继续使用公司网关，可以双击原来的 `start-gpt-image.command`，或在终端运行。首次输入后，密钥同样会保存在 macOS 钥匙串，后续启动无需重复输入：

```bash
cd "/路径/到/酒店素材工坊"
MODEL_PROVIDER=company \
API_GATEWAY_KEY="你的公司网关密钥" \
node demo/server.mjs
```

## 重要说明

- 不要把任何 API Key 发给别人、放进前端代码或提交到 GitHub。
- 豆包 API 的免费额度、模型权限和计费独立于 Codex 会员，以火山方舟控制台显示为准。
- 如果返回 401/403，通常是 API Key 无效、模型未开通或账号没有接口权限。
- 图片会以 Base64 方式从模型返回，服务端再返回给浏览器，避免使用临时图片链接。
- `tools-runtime.js` 是浏览器适配层：在安装包内通过 `window.bootframe` 调用 `media.cjs` 中原有 Sharp/FFmpeg 逻辑；直接打开网页时，图片工具用 Canvas 在本机生成下载文件，视频编码提示使用安装包内置处理器。
- 「一键去水印」「一键精修场景图」属于后续可计费的服务。去水印支持“局部框选”和“满屏水印”两种模式，始终通过本机服务调用当前配置的公司 GPT‑Image；上传原图后会把 `ratio=auto` 交给模型，避免把竖版海报强制按 16:9 处理。满屏模式会在提示词中明确区分重复半透明水印与有效标题、价格、日期、Logo 和产品内容；模型服务未启动、Key 未配置或公司网关未开通图片 API 时会直接报错，不会再静默使用本机网格擦除算法。场景精修仍可在模型不可用时回退到本机 Sharp/Canvas 演示算法。
- 重新打包 Electron 时以 `demo/electron-main.cjs` 为主进程、`demo/electron-preload.cjs` 为预加载脚本，依赖声明位于 `demo/package.json`；`media.cjs` 保留原安装包中的 Sharp、FFmpeg、矢量解析和 Logo 抠取逻辑。
- Demo 默认只生成一张图片；输出比例跟随所选模板自身的画幅，不在编辑面板中单独切换。
- 最终图片仍建议人工校对文字，尤其是酒店名称、价格、电话和活动日期。
- 不要再用 `python -m http.server` 打开这个 Demo。静态服务器不支持 `POST /api/generate-poster`。
- 如果浏览器曾经打开过 4173 等旧页面，刷新到启动脚本自动打开的 4174/4175/4180 页面即可；新版页面也会自动尝试连接这些本地模型端口，不再直接显示浏览器的 `Failed to fetch`。
- 推荐使用启动脚本打开 `http://127.0.0.1:4174/`、`4175/` 或 `4180/`。如果误双击打开 `demo/index.html`，新版会在本地服务已启动时通过 4174-4178、4180 读取素材后再导出；如果所有服务都未启动，请先运行启动脚本。
- 暖棕横版会在模型返回后检查左侧明暗关系；如果模型漏掉渐变蒙层，前端会自动补一层轻量深棕渐变，保证文字区域有足够对比度。
- 场景精修接模型的入口是本地服务的 `POST /api/retouch-scene`。启动 `demo/start-doubao.command` 或 `demo/start-gpt-image.command` 后，点击「开始精修场景图」会自动发送当前图片并返回模型结果；两个脚本都会弹窗输入一次 Key 并保存到本机钥匙串。未启动服务时不会报“模型成功”，而是明确回退到本机算法。
- 只有启动了上述模型服务并配置 Key，才会向对应的模型供应商发送图片；这类图片编辑调用按供应商账号的 API 用量计费，不会因为 Codex 会员而自动免费。未启动模型服务时不会产生模型调用费用。
- 本地模板编辑时，点击画布文字即可直接修改，插入光标会落在点击位置；选中文字会显示 Figma 风格蓝色边框、八向缩放控制点和文本框尺寸提示。拖动文字可移动，拖动文本框只改变宽高，字号保持不变，文字会按文本框宽度自动换行；字号仅由右侧字号控件调整。
